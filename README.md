🚀 Mini-Project

Project Name: Manufacturing Equipment Output Prediction.

Description: A Machine Learning project that predicts hourly manufacturing production output (Parts Per Hour) using machine parameters, material properties, operator experience, and machine utilization. Built using Python, Scikit-learn, and Streamlit.

Technologies Used: Python, Pandas, numpy, matplotlib, seaborn, scikit-learn, linear-Regression, Streamlit, Joblib, Jupyter Notebook.
